Prototype · GPU map engine preview

What the maps could look like in Mapbox

A working preview of the district map rendered as 3D extruded columns — height shows the number of Ukrainian refugees (Temporary Protection holders), and the base colour shows resident population. Drag to rotate, scroll to zoom, hover a district for detail.

About this preview. It runs on MapLibre GL JS, the open-source engine that shares Mapbox GL JS's API and rendering — so it needs no paid access token and runs straight from this file. A production Mapbox version would look essentially the same. The geometry and figures are read live from the dashboard's own moldova-adm1.js and data.js, so they match the live site exactly (UNHCR TP holders, 27 Apr 2026; NBS Census population, 2024).

How this compares to the current D3 / SVG maps

AspectCurrent (D3 + SVG)Mapbox / MapLibre GL
RenderingSVG vectors, CPUWebGL, GPU — smoother with many features
3D extrusionNot available (flat choropleth)Native fill-extrusion — height = a second variable
Pitch & rotateNoYes — tilt and spin the map
Two variables at onceOne (colour)Two (colour + height), e.g. refugees over population
Token / costNoneMapbox needs a token & has usage limits; MapLibre is free
Bundle weight~Light (D3 only)Heavier (~200 KB engine + style)
OfflineWorks (geometry inlined)Works for GeoJSON layers; basemap tiles need network
